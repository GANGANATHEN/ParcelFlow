# DEMO Portfolio 🚀

A stunning 3D interactive portfolio built with Next.js, React Three Fiber, GSAP, and Lenis.

## ✨ Features

- **3D Background** — Interactive floating shapes with React Three Fiber
- **Smooth Scrolling** — Lenis smooth scroll with GSAP ScrollTrigger
- **Scroll Animations** — Section reveals, parallax effects, stagger animations
- **Responsive Design** — Mobile-first with Tailwind CSS
- **Performance Optimized** — Lazy loading, code splitting, optimized 3D rendering

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Next.js 15 | Framework |
| React 19 | UI Library |
| TypeScript | Type Safety |
| Tailwind CSS | Styling |
| React Three Fiber | 3D Graphics |
| GSAP | Animations |
| Lenis | Smooth Scroll |
| Lucide React | Icons |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build
npm run build
```

## 📁 Project Structure

```
demo-portfolio/
├── app/
│   ├── sections/     # Page sections
│   ├── page.tsx      # Main page
│   ├── layout.tsx    # Root layout
│   └── globals.css   # Global styles
├── components/       # Reusable components
├── hooks/            # Custom React hooks
├── lib/              # Utilities
└── public/           # Static assets
```

## 🎨 Customization

- **Colors**: Edit `tailwind.config.ts`
- **3D Scene**: Modify `components/Canvas3D.tsx`
- **Animations**: Adjust `hooks/useScrollAnimation.ts`
- **Content**: Update files in `app/sections/`
